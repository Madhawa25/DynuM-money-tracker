DynuM My Money Tracker — GitHub Pages package

UPDATED IN THIS PACKAGE
- New DynuM app icon for Android/PWA installation.
- Apple touch icon for iPhone/iPad home-screen installation.
- Favicon for desktop browser tabs.
- Web app manifest updated with the new icon and DynuM theme colours.
- Existing app sections and mobile navigation retained.

PUBLISH TO GITHUB PAGES
1. Unzip this package.
2. Open the extracted my_money_tracker_v2 folder (or the folder containing index.html).
3. Upload/replace the files in the root of your existing GitHub Pages repository.
   Keep index.html and the icon/manifest files together in the same folder.
4. Commit the changes and wait for GitHub Pages to publish.
5. Open the website and refresh it.

INSTALL THE UPDATED ICON
- iPhone/iPad: remove the old home-screen shortcut, open the website in Safari, tap Share, then Add to Home Screen.
- Android: open the website in Chrome, use Install app or Add to Home screen. If the old icon remains, remove the shortcut and install again.
- Desktop: refresh the website; the favicon should update. Browser caching may delay the change.

IMPORTANT
Your existing money records are stored separately in each device's browser. Before replacing/updating the app, export a JSON backup from each device. This package does not add cloud sync; it only updates the app icon and web-app metadata.
